## 基础知识
### 编程与数据
+ [CS50: Harvard 大学计算机科学课程与项目](https://www.edx.org/cs50) 如果您以前从未接触过编程，是计算机科学的新手，或者只是想回到绝对的基础，那么这门在线课程非常适合您。它在在线 CS 社区中极其出名，大部分视频在平台和 YouTube 上均可免费观看。交互式实践环节（通常）也是免费的，但证书需要付费。
![Video](https://img.shields.io/badge/Video-red)
![Paid](https://img.shields.io/badge/Paid-orange)
![Free](https://img.shields.io/badge/Free-yellow)

+ [Think Python 🐍](https://allendowney.github.io/ThinkPython/index.html) 这是一个关于 Python 编程和像计算机科学家一样思考的绝佳入门（或复习）指南。它使用 Jupyter Notebooks 作为逐步执行代码的主要方法，并提供了一些最清晰的解释。此外，书中包含大量练习，并教会您_如何以及何时_使用“虚拟助手”或 LLM 来辅助编程。
    ![Free](https://img.shields.io/badge/Free-yellow)
    ![Text](https://img.shields.io/badge/Text-blue)

+ [HyperSkill](https://hyperskill.org/courses) 一个交互式编程平台，具有学习连续打卡、在线代码编辑器和移动应用。非常适合随时随地练习，并设有 Python 和 AI 专项学习路径。虽然有高级版本，但在撰写本文时，免费档位已足以进行基础编程技巧练习。
![Text](https://img.shields.io/badge/Text-blue)
![Paid](https://img.shields.io/badge/Paid-orange)
![Free](https://img.shields.io/badge/Free-yellow)

+ [NumPy](https://numpy.org/learn/) NumPy 是 Python 中的一个数学包，它是许多机器学习和 AI 模型的核心，因为它使处理数组、矩阵和其他形式的数据变得非常简单。在掌握 Python 基础后，这通常是立即采取的第一步。请尽早尝试适合您的入门课程。
![Text](https://img.shields.io/badge/Text-blue)
![Free](https://img.shields.io/badge/Free-yellow)

+ [pandas](https://pandas.pydata.org/docs/getting_started/intro_tutorials/index.html) pandas 是一个用于处理数据结构的基础 Python 包。它是 ML 中最常用的处理和分析数据的工具之一。学习 Python 基础语法始终是第一步，但一段时间后，在深入 AI 模型之前，您需要开始学习数据处理。这是一个简短但足以让您熟悉该包的入门指南。
![Text](https://img.shields.io/badge/Text-blue)
![Free](https://img.shields.io/badge/Free-yellow)

+ [Scikit-learn Crash Course - Python 机器学习库](https://www.youtube.com/watch?v=0B5eIE_1vpU&ab_channel=freeCodeCamp.org) Scikit-Learn 是一个强大的 Python 机器学习库，支持监督和无监督学习算法。它是开始观察并学习如何将数据输入基础 ML 算法并查看基础结果的_非常好_的起点 —— 这将在您阅读论文、书籍以及参加 ML/AI 课程时提供很多上下文。
![Video](https://img.shields.io/badge/Video-red)
![Free](https://img.shields.io/badge/Free-yellow)

+ [PyTorch Tutorials](https://docs.pytorch.org/tutorials/) PyTorch 是研究中用于 AI/ML 的主要框架。官方教程系列非常出色，在完成基础 Python 练习后值得花时间研究。同时也可以看看 YouTube 播放列表！该资源同时出现在本仓库的 ML 和编程资源列表中。
![Video](https://img.shields.io/badge/Video-red)
![Text](https://img.shields.io/badge/Text-blue)

![Text](https://img.shields.io/badge/Text-blue)
![Free](https://img.shields.io/badge/Free-yellow)


+ [Git and GitHub for Beginners - Crash Course](https://www.youtube.com/watch?v=RGOj5yH7evk&ab_channel=freeCodeCamp.org) 学习 GitHub 基础的另一种视频版本。不要被视频的长度吓到 —— 一步步来，它是值得的！

+ [Anaconda Beginners Guide for Linux, Mac and Windows - Python 工作环境教程](https://www.youtube.com/watch?v=MUZtVEDKXsk&ab_channel=PythonSimplified) Anaconda (又称 Conda) 是一个虚拟环境管理工具集。在使用 Python 编程时，特别是处理复杂的 AI/ML 系统时，您通常需要调用大量库（包）来运行程序。但这意味着您的程序依赖于这些库的存在，且每种模型的需求都不同。虚拟环境是管理这些环境的一种方式，对于简化您的工作至关重要！
